# One-Liner Laugh Lab

A make.fun bounty entry for [u-suroso-69-one-liner-laugh-lab-6ccf3aae](https://make.fun/bounty/u-suroso-69-one-liner-laugh-lab-6ccf3aae).

This program writes one short funny line to `/output/entry.txt`: the excuse a robot vacuum gives after eating a sock. The vacuum denies everything in the calm, legalistic voice of a machine that has already been caught — the sock, it insists, entered the dustbin of its own free will.
